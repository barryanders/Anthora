# Book sample imagery

Created September 12, 2026 with the built-in OpenAI image-generation tool for Anthora's book previews. Each PNG contains four fictional editorial scenes in a 2×2 atlas. No stock-photo service, downloaded third-party photo, user library photo, or third-party reference image was used. Original generated PNGs and provenance metadata are retained; these copies are bundled for offline display.

Samples are preview artwork only. They are never placed into a user's book project or PDF. The interface labels them as AI-generated and offers a persistent Show sample photos switch. No attribution to a stock photographer is implied.
