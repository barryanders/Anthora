# Free edition

All Anthora features are free. The interface has no activation flow, upgrade
button, purchase link, or license lookup. Books, PDF export, and Library Care
are available without a key. The service retains its free-valued license API
only for compatibility with older clients; it does not contact a licensing
provider or read saved license keys. Third-party copyright/license notices
remain because they are software attribution, not a paid-app requirement.

Checked October 29, 2026: production web build, 39 web tests, and three service
free-access tests. This source update does not create a new packaged Mac release.
